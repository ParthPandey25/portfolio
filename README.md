## 🚀 About This Portfolio

This is my personal portfolio website — a hacker-themed, terminal-inspired interactive site built with **Next.js**, **Framer Motion**, and **Tailwind CSS**. It's designed to give recruiters and fellow engineers a fast, immersive look at who I am and what I can do.

### ✨ Key Features

| Feature | Description |
|---|---|
| 🖥️ **Terminal Hero** | Interactive bash-style terminal with runnable commands (`./whoami.sh`, `./tryhackme.sh`, `./contact.sh`) |
| ⚡ **Boot Sequence** | Hacker-style boot animation on first load |
| 📊 **TryHackMe Stats** | Live stats display — rank, rooms, streak, badges |
| 🎯 **Experience Timeline** | Expandable cards for 15+ roles with STAR-method bullet points |
| 📜 **Credential Grid** | Filterable wall of 40+ certificates with PDF viewer links |
| 🔬 **Project Vault** | Showcase of hands-on projects with tech stack tags |
| 📝 **Publications** | Research papers and conference presentations |
| 🌊 **Interactive Background** | Animated particle field that responds to mouse movement |
| 📱 **Fully Responsive** | Works on mobile, tablet, and desktop |

### 🛠️ Tech Stack

```
Framework    → Next.js 16 (App Router + Turbopack)
Styling      → Tailwind CSS 4
Animations   → Framer Motion
Icons        → Lucide React
Deployment   → Vercel (auto-deploys on git push)
```
